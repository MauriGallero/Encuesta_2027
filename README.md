# Encuesta - Elecciones Presidenciales 2027 🇦🇷

Formulario de encuesta responsive hecho en HTML y CSS como proyecto final del curso de Responsive Web Design de freeCodeCamp.

### 🔗 Demo en vivo
https://MauriGallero.github.io/encuesta-2027/

### 🚀 Tecnologías
- HTML5
- CSS3 (Flexbox, responsive)

### 📋 Características
- Formulario validado (name, email, number)
- Inputs tipo radio y checkbox
- Diseño responsive y accesible
- Cumple los 17/17 tests de freeCodeCamp

### 📦 Cómo verlo local
1. Clona el repo
2. Abre `index.html` en tu navegador
